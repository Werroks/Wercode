## Этап 2 (2026-11-11): что сделано

- Вкладки: Ctrl+Shift+T — новая, Ctrl+Tab / Ctrl+Shift+Tab и Ctrl+PageDown / PageUp — переключение, Ctrl+Shift+Q или средний клик — закрыть вкладку. Новая вкладка стартует в корне проекта.
- Сплиты: Ctrl+Shift+D — вправо, Ctrl+Shift+E — вниз, Ctrl+Alt+стрелки — переход между панелями, Ctrl+Shift+W — закрыть панель; разделитель тянется мышью. Новая панель открывается в каталоге той, из которой её разделили.
- Закрытие: если в терминале ещё работает программа, сначала вопрос (Enter — закрыть, Esc — отмена); `confirm_close = false` в settings.toml отключает. Шелл, вышедший с кодом 0, забирает панель с собой; последняя закрытая вкладка заменяется новой.
- Каталог шелла: PowerShell сообщает его при каждом приглашении (OSC 9;9, `shell_integration`); виден в названии вкладки.
- Ссылки: Ctrl+клик по URL открывает браузер, по существующему пути — файл в системной программе (до появления редактора); понимает `file:12:5` и `file(12,5)`.
- Мышь для программ (vim, htop, TUI): нажатия, перетаскивание, колесо; Shift возвращает обычное выделение.
- Tab и Shift+Tab уходят в шелл, а не в переход по фокусу. Курсор мигает (`cursor_blink`). Ресайз PTY с задержкой 60 мс.

Проверено автотестами (24 теста, из них 4 — интерфейс в окне без экрана: реальные привязки клавиш, раскладка сплитов, перетаскивание разделителя, вопрос при закрытии занятого терминала). PowerShell через ConPTY действительно сообщает каталог после `cd` — отдельный тест.

Не проверено руками: всё перечисленное выше в настоящем окне; сочетания клавиш в русской раскладке; Ctrl+клик и подчёркивание ссылок; мышь в vim/htop; внешний вид панели вкладок с несколькими вкладками и сплитами (скриншот есть только с одной вкладкой).

Осторожно: `replica/shot.ps1` с текстом для набора печатает в активное окно. Если Windows не вывела Wercode вперёд, нажатия уходили в чужую программу — так случилось 2026-11-11. Теперь скрипт в этом случае останавливается, ничего не набирая и не снимая.

Служебное: `WERCODE_DEBUG_KEYS=1` печатает каждое нажатие в stderr; `replica/shot.ps1` снимает скриншот окна.
